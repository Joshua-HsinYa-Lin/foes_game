# 允望樂園

[English](README.md)

允望樓開幕夜的瀏覽器射擊遊戲。輸掉運送合約的鹹魚船長，派鹹水幫來搗亂。可以玩故事、和電腦大亂鬥，或在同一個 Wi-Fi 下和朋友對戰。

## 開始玩

- **電腦：** 下載 [yunwang_paradise.zip](yunwang_paradise.zip?raw=true)，解壓縮後用 Chrome、Edge 或 Firefox 開啟 `yunwang_paradise.html`。不用安裝，可離線玩。
- **手機、平板：** 從執行伺服器的電腦開啟（見下方「區網對戰」）：用 Chrome 或 Safari 開 `http://<位址>`，手機橫拿。iPhone 用「分享 → 加入主畫面」可全螢幕。

## 模式

- **故事模式：** 五個章節，含劇情對話。
- **樂園大亂鬥：** 和電腦對戰，最後站著的人獲勝。
- **區網對戰：** 大亂鬥、紅藍對戰，或全家合作（大家一起打電腦，倒下的人會復活）。
- 難度 1（新手）到 5（困難）。

## 角色

| 角色 | 技能 |
| --- | --- |
| 允望，主廚 | 爆炒烈焰，同時回血 |
| Luap，拳擊手 | 旋風連打衝刺 |
| Auhsoj，工程師 | 自動砲台 |
| Meibao，甜點師 | 珍奶補給：回血加速 |
| 阿風，外送員 | 包裹炸彈，丟到瞄準的地方 |
| 小泡，洗碗工 | 替隊友加上泡泡護盾 |
| 金金，收銀員 | 扇形撒出硬幣 |
| 冰師傅，冷藏庫 | 急凍霧，讓敵人變慢 |

角色玩越多等級越高，從 1 到 9 級（每級生命與傷害 +4%）。4 級解鎖**廚房道具**（G，每場 3 次），6 級解鎖**招牌絕活**，8 級解鎖**大火快炒**（V：造成傷害會累積火力，滿了可以 6 秒內更快、更痛、更耐打，技能也變強）。在選角畫面挑選；「試玩：全部解鎖」可以讓所有角色直接滿級。

## 操作

| 電腦 | 動作 |
| --- | --- |
| WASD／滑鼠／左鍵 | 移動／瞄準／攻擊（地上的指示線會顯示攻擊方向） |
| 右鍵（按住、放開）或 X | 技能 |
| G／V／H | 廚房道具／大火快炒／喝雞湯 |
| F、Q 或滾輪、1-4、R、C | 撿起或開車、換武器、換彈、丟掉 |
| 空白鍵／Shift／M／Esc | 奔跑／跳躍／地圖／暫停 |

**觸控：** 左手拇指移動；右手拇指拖曳瞄準、放開射擊（輕點自動瞄準）；從技能鈕拖曳可瞄準技能；武器欄、雞湯、道具與小地圖都可以點。

**畫面：** 在標題畫面或暫停選單選「2D 平面」或「2.5D 立體」。只影響自己螢幕的畫法，兩種看到的地圖範圍一樣大，用不同畫面的人也可以一起玩。

## 區網對戰

1. 在一台電腦安裝 [Node.js](https://nodejs.org) 16 以上版本，在這個資料夾執行 `node server.js`（或雙擊 `start-lan-server.bat`／執行 `./start-lan-server.sh`）。畫面會顯示位址，例如 `192.168.1.23:8080`。
2. 同一個 Wi-Fi 的人開啟 `http://<那個位址>`，或開啟 HTML 檔後輸入位址。選角色後按「區網對戰」。
3. 第一個進來的人是房主，可以設定電腦玩家數量、難度和模式，再按「開始對戰」。

已測試 8 人同房。選項：`node server.js --port 8080 --bots 13 --difficulty 4 --mode coop`；`--autostart 15` 會自動開始；`--stats` 會顯示負載與網路用量。

## 其他

六個隱藏細節（標題畫面會計數）、可以打壞的木造建築、冷鏈空投、可以開的小貨車和機車（含手煞車甩尾）、勝利與擊倒音效，以及允望樓主題曲。

## 開發者

| 路徑 | 內容 |
| --- | --- |
| `js/data.js` | 角色、武器、等級、道具、絕活、章節 |
| `js/sim.js` | 遊戲模擬（瀏覽器和伺服器共用） |
| `js/render.js` | 2D 與 2.5D 畫面、介面 |
| `js/client.js` | 選單、操作、連線 |
| `js/i18n.js`、`js/audio.js` | 中英文字、音樂與音效 |
| `server.js` | 區網伺服器，不需安裝套件 |
| `assets/` | 音樂與錄音音效（原始檔在 `assets/sfx/original/`） |
| `prototype/pinefall.html` | 早期原型 |

修改 `js/`、`css/`、`assets/` 或 `index.html` 之後，執行 `node tools/build_single.js` 重新產生單一 HTML 檔和 zip。

測試：`node tests/sim_test.js` 不需要其他東西。`tests/` 裡的瀏覽器測試需要 Playwright；`lan_test.js`、`family_test.js`、`view_modes_test.js` 和 `mobile_test.js` 的連線部分需要先執行 `node server.js --port 8099`。
